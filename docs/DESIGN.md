# 桌面界面设计

沿用上游桌面应用的字号、侧栏和主题，以减少账号管理到 API 管理的认知切换。基础色为白色 #FFFFFF、正文 #202124、次级文字 #71717A、分隔线 #E4E4E7，运行状态使用 #10B981；暗色模式采用现有主题变量。标题沿用 Bricolage Grotesque，正文沿用系统中文字体。

布局：左侧既有导航，右侧依次为连接地址与启停、引擎配置、账号同步与停用、模型检查和调用示例。接入地址是主信息，只有连接区域使用浅底，不将所有内容切成同质卡片。实际状态优先，初始空列表不填入演示模型。

预览版不连接账号、不启动引擎，明确标注不可操作。所有输入都有标签，动态错误使用 role=alert；桌面最低宽度下允许按钮换行。

## 2026-10-20：像素橘猫品牌改版

参考用户提供的像素橘猫图，采用独立猫头图标；品牌蓝 #0866EB、导航深蓝 #0745A4、闪光金 #FFD24A、正文墨蓝 #172A46、工作区冰蓝 #F3F7FD、白色 #FFFFFF。标题用 Bricolage Grotesque，中文与表格保持系统字体。像素元素只用于品牌，不牺牲小字号可读性。

布局：左侧蓝色导航，以猫头与两行品牌名为视觉锚点，金色表示当前页面；右侧左对齐的浅色工作区，Proxy 页以接入地址为主操作面板。深色模式使用蓝灰工作区与更亮的交互色。

评审：去掉满屏爆炸纹理和重复猫咪贴纸，让图标承担趣味表达，避免装饰干扰账号、积分与 API 的真实状态。保留服务商自身标识以帮助区分账号类型。

## 2026-10-26：桌面操作层级与预览安全

沿用既有蓝色品牌、主题变量和组件，不更换视觉主题。账号页状态图标提供可访问名称；“添加与迁移”面板移除不承载信息的圆形装饰；设置说明使用完整的次级文字色。代理页的预览说明明确示例地址 `127.0.0.1:8317` 不会读取本机账号或启动代理，预览模式下操作不可用；空账号池文案说明添加账号后再返回。

验证记录：本轮 in-app browser 不可用（宿主返回 `Browser is not available: iab`），改用一个专用 Chrome 标签访问 loopback 合成预览并检查账号、代理、设置页面与键盘焦点。第一次截图将 `VITE_PAGES_DEMO=1` 的 `/workbuddy-switch/` GitHub Pages base 用在根路径本地服务器，导致静态图标请求路径错误；正式 Tauri 构建使用 `/` base，Vite 产物和应用二进制均包含正确的图片资源。改用 `VITE_DEMO_MODE=1` 且不设置 `VITE_PAGES_DEMO` 后重新截图。合成预览不代表 macOS Tauri/WKWebView 原生渲染验证。Hallmark 的静态扫描器因本项目入口为 TSX 且没有静态 HTML 页面，未执行其渲染检查；Impeccable 的渲染审计按其适用说明不支持 macOS WKWebView，因此未执行。

工具记录：本轮一次 `process-run --project .` 从 build staging 子目录调用，因 `.` 不是已登记的项目根目录而在启动前拒绝；没有 entry 或命令进程。改从项目根目录调用后打包成功。后续从独立 staging 目录运行登记命令时，`--project` 应保持项目根目录语义。
